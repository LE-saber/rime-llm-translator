# Rime LLM Translator v0.3.0

面向 **Ubuntu 24.04 amd64 / GNOME 46 / IBus / 朙月拼音** 的正式安装包。普通中文与繁体保留；不支持 Windows。

## 本版内容

- 包内原生 Bergamot INT8 离线英日模型，无 pip、GPU 或首次模型下载。
- 可编辑长文本悬浮框，置顶、拖动缩放、灰白 / Dracula 主题与 GUI 设置。
- 最近选择的真实输入框接收译文，排除悬浮框和设置框；关闭未发送文本可从本机记录找回。
- 实时机翻预览；API 配置后默认开启 AI 发送，可关闭。等待显示转圈和秒数，失败保留原文。
- 可录制快捷键、旧环境清理及完整 CI / 资源报告。

## 安装 / 升级

下载 Assets 中 `.deb` 和 `SHA256SUMS` 到同一目录：

```bash
sha256sum --check SHA256SUMS
sudo apt install ./rime-llm-translator_0.3.0_amd64.deb
# 新用户：
rime-llm-translator setup && rime-llm-translator enable
# 旧用户改运行以下命令，保留 API Key 和配置：
# rime-llm-translator sync && rime-llm-translator enable
```

**注销再登录**，添加 / 选择中文 → Rime Translator。若全局禁用 GNOME 用户扩展，请先启用；`doctor` 应显示桥接 active。打开长文本默认 Alt+Space（若冲突，在 GUI 改键），发送默认 Ctrl+Enter。

## 附件与验证范围

- `rime-llm-translator_0.3.0_amd64.deb`：正式安装包。
- `SHA256SUMS`：安装包 SHA-256。
- `RESOURCE_REPORT.md` / `mt-benchmark.json`：该构建的磁盘、内存、延迟与公开译文样本。系统依赖另计，runner 数据不代表虚拟机性能。

GitHub Ubuntu CI 检查单元测试、真实 Rime / IBus / GTK、GNOME 46 Wayland 实际发送与焦点隔离、模拟 API、断网模型推理和安装。虚拟机 CPU 需 SSE4.1；离线译文为基本草稿（日文经英文中转），实际云端质量及用户具体应用仍需手动验收。
